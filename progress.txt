2026-10-29 follow-up — batching clarification
User asked whether CorrectionLib can batch. Rechecked the pinned fork's
src/python.cc: evalv accepts arrays, allocates the output once, releases the
Python GIL, and loops in C++, calling scalar c.evaluate(inputs) for each item.
Our array workloads DO use that path; there is no Python loop over items.
PluginNode::evaluate accepts one item's arguments and returns one double, so
the plugin itself receives no batch. The 16-output workload makes 16 independent
array calls. A batch callback plus evaluator dispatch would require extending
the fork; this is possible, but absent from the pinned SDK. No code or timing
changes were needed for this clarification.
